## 二、第二章：级联视觉感知与6D位姿估计

### 2.1 理论逻辑链

```
RGB图像(整图)
    │
    ▼
[YOLOv8-seg] ──→ {检测框B_i, TagID, 置信度s_i, 实例掩膜M_i} ×N个目标
    │
    ▼ (对每个目标i)
[动态ROI裁剪] ──→ 256×256的ROI图像 I_roi
  (γ(s) = γ_min + (γ_max - γ_min)(1-s))
  (记录仿射变换矩阵用于坐标回映)
    │
    ▼
[改进DeepLabV3+] ──→ {4通道关键点热力图Ĥ_j, 1通道线缆掩膜M̂_c}
  (双分支输出头: 关键点分支 + 线缆分割分支)
    │
    ├──→ soft-argmax提取关键点2D坐标 (û_j, v̂_j) ──→ 逆仿射回映到原图坐标
    │
    └──→ 线缆掩膜阈值化 → CableMask二值图 ──→ 输出给Ch3/Ch4
    │
    ▼
[EPnP + RANSAC] ──→ 相机系下位姿 ^C T_O = (R, t)
  (输入: 4个2D关键点 + CAD对应3D点 + 相机内参K)
    │
    ▼
[手眼标定链] ──→ 基座系下位姿 ^B T_O = ^B T_E · ^E T_C · ^C T_O
```

## 三、第三章：电连接器自主抓取方法

### 3.1 理论逻辑链

```
Ch2输出: {^B T_O, 实例掩膜M_i, CableMask, 深度图}
    │
    ├──[1. 目标局部点云构建]
    │   │
    │   ├── 实例掩膜裁剪深度图 → 像素-深度对{(u,v,z)}
    │   ├── 深度反投影: P_i^c = z·K^{-1}·[u,v,1]^T → 相机系点云P^c
    │   ├── 坐标系变换: P_i^O = (^C T_O)^{-1} · P_i^c → 物体系点云P^O
    │   └── 线缆禁入域权重: w_i = σ(d_cable/λ) 或 阈值形式
    │
    ├──[2. 端到端6D抓取生成]
    │   │
    │   ├── 改进Contact-GraspNet: PointNet++骨干 → 4分支预测头
    │   │   ├── 闭合方向分支 → v' → 标准化 → x
    │   │   ├── 接近方向分支 → u' → 正交化 → z
    │   │   ├── 抓取得分分支 → s_i ∈ [0,1]
    │   │   └── 夹爪宽度分支 → ω_i
    │   │
    │   └── 位姿恢复: R_g = [x, x×z, z], t_g = c + ω/2·x - d·z
    │       → 候选抓取集合 G = {g_i}
    │
    ├──[3. 多约束抓取筛选]
    │   │
    │   ├── IK可达性: C_IK(g_i) ∈ {0,1}, 关节裕量J_lim, 可操作度w(q)
    │   ├── 线缆安全间隙: S_clearance = min(1, d_i/d_ref)
    │   ├── 姿态相容性: S_align = v_grasp · v_asm / (‖·‖·‖·‖)
    │   └── 综合评分: S_total = w1·S_quality + w2·S_clearance + w3·S_align
    │       → 最优抓取 g*
    │
    └──[4. GRRT-Connect运动规划]
        │
        ├── 混合障碍物地图构建
        │   ├── 刚性障碍: 舱壁AABB包围盒 → O_rigid
        │   └── 线缆障碍: CableMask反投影→点云→Octomap体素 → V_cable
        │       → M_hyb = (O_rigid, V_cable)
        │
        ├── 线缆方向估计: PCA on P_cable → d_c (特征值消歧)
        │
        ├── 引导式采样与扩展
        │   ├── 方向相容代价: φ_align(q) = 1 - |a(q)^T · d_c|
        │   ├── 各向异性安全度量: d_ani(x) = √((d⊥/r⊥)² + (d∥/r∥)²)
        │   ├── 综合代价: J_dir(q) = α·d_g + β·exp(-d_r/σ_r) + γ·exp(-d_ani/σ_c) + δ·φ_align
        │   └── 接纳概率: P_acc(q) = exp(-J_dir/T)
        │
        └── 路径后处理: 捷径替换 → J_path梯度优化(平滑+长度+障碍) → B样条拟合
            → 最终轨迹 π*
```

### 3.2 每一步的传感器/数据来源与算法

| 步骤 | 输入数据 | 数据来源 | 算法/操作 | 输出数据 | 后续去向 |
|------|----------|----------|-----------|----------|----------|
| 1. 局部点云裁剪 | 实例掩膜+深度图 | Ch2 YOLOv8-seg + RealSense depth | 掩膜索引→像素-深度对 | {(u,v,z)} 集合 | 反投影 |
| 2. 深度反投影 | {(u,v,z)}, K | 步骤1 + 相机标定 | P^c = z·K^{-1}·[u,v,1]^T | 相机系局部点云 | 坐标变换 |
| 3. 坐标系变换 | P^c, ^C T_O | 步骤2 + Ch2位姿 | P^O = (^C T_O)^{-1}·P^c | 物体系规范化点云 | 网络输入 |
| 4. 线缆禁入域 | CableMask+深度 | Ch2线缆掩膜 + depth | 反投影→d_cable计算→权重w_i | 点级采样权重 | 网络输入/损失 |
| 5. 抓取网络训练 | 仿真/真实标注抓取数据 | 仿真器(IsaacSim)+真实标注 | Contact-GraspNet: L_score+L_width+L_pose | 训练好的抓取模型 | 推理 |
| 6. 抓取网络推理 | P^O + w_i | 步骤3+4 | PointNet++前向→4分支→标准化正交化→位姿恢复 | 候选集合G={g_i} | 筛选 |
| 7. IK可达性 | g_i | 步骤6 | 逆运动学求解(分析解/数值解) | C_IK, q_i*, J_lim, w(q) | 筛选 |
| 8. 线缆安全间隙 | g_i, V_cable | 步骤6+地图 | 夹爪扫掠体积vs线缆体素最小距离 | S_clearance(g_i) | 筛选 |
| 9. 姿态相容性 | g_i, v_asm | 步骤6+装配轴线 | 内积余弦 | S_align(g_i) | 筛选 |
| 10. 综合评分 | S_quality,S_clearance,S_align | 步骤6-9 | 加权求和→排序→取最优 | g* | 规划起点 |
| 11. 刚性地图构建 | 舱壁CAD/测量 | 离线测量/CAD | AABB包围盒生成 | O_rigid | 碰撞检测 |
| 12. 线缆三维化 | CableMask+depth | Ch2+RealSense | 反投影→手眼变换→Octomap插入 | V_cable体素集 | 碰撞检测 |
| 13. 线缆方向估计 | P_cable^W | 步骤12 | PCA: 协方差矩阵→最大特征向量→消歧 | d_c单位向量 | 引导采样/Ch4前馈 |
| 14. GRRT-Connect | q_start,q_goal,M_hyb,d_c | 步骤10+11+12+13 | 引导式双树扩展+方向接纳+各向异性安全判据 | 初始路径π | 后处理 |
| 15. 路径后处理 | π, M_hyb | 步骤14+地图 | 捷径替换→J_path梯度下降→B样条拟合 | 优化轨迹π* | 执行 |

## 四、第四章：柔顺装配控制方法

### 4.1 理论逻辑链

```
Ch3输出: {g*(预装配位姿), d_c(线缆方向), π*(运动轨迹)}
Ch2输出: {CableMask → v̂_cable方向向量}
    │
    ├──[1. 装配误差分解]
    │   ├── 横向对齐误差: e_xy = (I - z_h·z_h^T)·Δp
    │   ├── 轴向推进误差: e_z = z_h^T·Δp
    │   └── 姿态失配误差: e_R = Log(R_h^T·R_c)^∨
    │       → 装配误差向量 e_t = [e_xy; e_z; e_R]
    │
    ├──[2. 线缆等效建模]
    │   ├── 方向映射: v̂_cable = ^B R_C · ^C v̂_cable (归一化)
    │   ├── 等效伸长: Δl = v̂_cable^T · Δp
    │   └── 等效弹性-阻尼力: F_cable = (k_c·Δl + c_c·Δ̇l)·v̂_cable
    │
    ├──[3. 视觉前馈变刚度阻抗控制器]
    │   ├── RL输出 → EMA平滑 → 期望位姿X_d^(k)
    │   ├── 位姿误差: e = [e_p; e_o]
    │   ├── 前馈补偿: f_ff = F̂_cable, 推进力: f_d = f_d·z_h
    │   ├── 参考力: f_ref = f_d + f_ff
    │   ├── 任务力矩: τ_task = J^T·(f_ref - K_c·e - D_c·J·q̇)
    │   ├── 零空间: τ_null = P_null·[K_null·(q_null-q) - D_null·q̇]
    │   └── 总指令: τ_cmd = τ_task + τ_null + τ_coriolis (+ 力矩限幅)
    │
    ├──[4. RL环境构建]
    │   ├── 状态: s_t = [o_t^img(多视角RGB), o_t^pro(位姿差/q/q̇/f_t/g_t)]
    │   ├── 动作: a_t = [a_t^eef(6D连续末端增量), a_t^grip(离散夹爪)]
    │   ├── 奖励: 稀疏(成功+1, 失败-λ_fail, 夹爪惩罚)
    │   └── 成功判定: d_pose≤ε_p ∧ Δz_ins≥z_min ∧ F_ins≤F_max ∧ C_img≥τ
    │
    ├──[5. SAC策略学习(RLPD)]
    │   ├── 视觉编码: ResNet-10(冻结) → e_i → MLP_enc → z_s
    │   ├── Actor: π_θ(a^eef|s) 高斯策略, L_π = -E[Q_φ - αlog π_θ]
    │   ├── Critic: Q_φ(s,a^eef) 软贝尔曼TD + 蒸馏, L_Q = TD误差 + λ_dist·蒸馏
    │   ├── 夹爪值网络: Q_ψ(s,a^grip) DQN形式
    │   ├── 行为克隆辅助: L_BC = E[‖μ_θ(s)-a^exp‖²]
    │   └── 人在回路: 示教→D_human, 接管→D_exp, 分池回放→B
    │
    └──[6. 虚实迁移]
        ├── IsaacSim仿真预训练(域随机化: δ_p,δ_R,δ_c,δ_l,k_l,c_l,μ,η_f)
        └── 真实平台在线精化(加载检查点→RLPD继续训练)
```

### 4.2 每一步的传感器/数据来源与算法

| 步骤 | 输入数据 | 数据来源 | 算法/操作 | 输出数据 | 后续去向 |
|------|----------|----------|-----------|----------|----------|
| 1. 装配误差计算 | ^B T_O(连接器), ^B T_H(插孔) | Ch2位姿+已知插孔位置 | 矩阵运算→e_xy,e_z,e_R | 误差向量e_t | 控制器 |
| 2. 线缆方向变换 | ^C v̂_cable | Ch2 CableMask PCA | ^B R_C变换+归一化 | 基座系v̂_cable | 等效建模 |
| 3. 等效伸长计算 | Δp, v̂_cable | 步骤1+2 | Δl = v̂_cable^T·Δp | 标量Δl及Δ̇l | 前馈力 |
| 4. 前馈补偿力 | Δl, Δ̇l, k_c, c_c | 步骤3+参数辨识 | F_cable = (k_c·Δl+c_c·Δ̇l)·v̂_cable | 前馈力f_ff | 控制律 |

| 8. EMA平滑 | X_target=X_c+ΔX_RL | 步骤7 | 位置线性插值+四元数Slerp | 平滑X_d^(k) | 控制律 |
| 9. 阻抗力矩计算 | e, q̇, J, f_ref | 步骤1-8 | τ_task=J^T(f_ref-K_c·e-D_c·Jq̇) | τ_task | 合成 |

| 12. 示教采集 | 操作员动作 | 示教设备 | 记录(s,a)序列 | D_human数据池 | RL训练 |
| 13. 成功判定器训练 | 终态图像+标签 | 人工标注成功/失败 | 二分类CNN(BCE损失) | C_img分类器 | 环境奖励 |
| 14. IsaacSim仿真训练 | 仿真环境 | IsaacSim+域随机化 | SAC+RLPD, 均衡采样 | θ*_sim, φ*_sim, ψ*_sim | 迁移 |
| 15. 真实平台精化 | 仿真检查点+真实交互 | 步骤14+真实平台 | RLPD在线训练+人在回路 | 最终策略π_θ | 部署 |

## 七、关键数据流追踪：从传感器原始信号到最终装配

以下追踪一个完整装配周期中每一个数据的完整生命周期：

### 7.1 RGB图像的完整生命周期

```
RealSense D435i → RGB帧(1280×720)
  → Ch2 YOLOv8-seg → 检测框+掩膜+TagID
    → ROI裁剪(256×256)
      → Ch2 DeepLabV3+ → 关键点热力图+线缆掩膜
        → soft-argmax → 2D关键点坐标
          → EPnP → ^C T_O
            → 手眼变换 → ^B T_O → Ch3抓取目标/Ch4装配目标
        → CableMask
          → Ch3反投影→Octomap(障碍物)
          → Ch3 PCA → d_c(线缆方向) → Ch4前馈补偿
  → Ch4 RL状态的o_t^img分量(多视角裁剪后128×128)
```

### 7.2 深度图的完整生命周期

```
RealSense D435i → Depth帧(aligned to RGB)
  → Ch3: 实例掩膜索引 → 目标像素深度
    → 反投影P^c = z·K^{-1}·[u,v,1]^T → 局部点云
      → 坐标变换 → 物体系点云P^O → Contact-GraspNet输入
  → Ch3: CableMask索引 → 线缆像素深度
    → 反投影 → 线缆3D点云P_cable
      → Octomap体素化 → V_cable
      → PCA → d_c
```

### 7.3 六维力/力矩信号的完整生命周期

```
ATI Gamma → F/T(6维) @1000Hz
  → 零点补偿+滤波
    → Ch4 控制器: f_ext (阻抗控制律的外力输入)
    → Ch4 RL状态: o_t^pro中的f_t分量
    → Ch4 安全判定: ‖f‖ > F_safe → 终止
    → Ch4 成功判定: F_ins ≤ F_max
    → Ch5 实验记录: 接触力时域曲线
```

### 7.4 关节角信号的完整生命周期

```
机械臂编码器 → q(7维), q̇(7维)
  → 正运动学 → ^B T_E (末端位姿)
    → 手眼链: ^B T_O = ^B T_E · ^E T_C · ^C T_O
  → Ch3 IK判别: f(q)=g_i 是否有解
  → Ch4 控制器:
    → Jacobian J(q) 计算
    → 零空间投影P_null = I - J^T(J^+)^T
    → τ_task = J^T(·)
    → τ_coriolis 动力学计算
  → Ch4 RL状态: o_t^pro中的q_t-q_0, q̇_t分量
```

## 八、需要特别注意的章节接口与逻辑一致性

### 8.1 Ch2→Ch3 关键接口

- **实例掩膜**用于裁剪目标像素以生成局部点云，必须保证掩膜质量（遮挡下不严重断裂）
- **CableMask**同时服务于：(a)Ch3线缆三维化建图(b)Ch3线缆禁入域权重(c)Ch3 PCA方向估计(d)Ch4前馈补偿方向
- **6D位姿^C T_O**用于Ch3点云从相机系变换到物体系，精度直接影响抓取候选分布

### 8.2 Ch3→Ch4 关键接口

- **最优抓取位姿g***成为装配阶段的"预装配初值"，其与装配轴线的对齐度(S_align)直接影响Ch4 RL需要修正的初始误差大小
- **线缆方向d_c**在Ch3中用于方向相容规划，在Ch4中用于前馈补偿力方向——必须是同一个估计结果
- **规划轨迹π***将机械臂从当前构型运送到预装配位姿，Ch4从该终点位姿开始装配

### 8.3 Ch2→Ch4 关键接口

- **CableMask → v̂_cable**线缆方向向量从视觉坐标系到控制任务坐标系的变换必须经过完整的手眼链: ^B R_C · ^C v̂_cable
- 该方向向量决定了线缆等效弹簧-阻尼力F_cable的注入方向，是Ch4视觉前馈补偿的核心

### 8.4 论文全局一致性检查点

- [ ] ^E T_C手眼矩阵在Ch2标定、Ch3坐标变换、Ch4方向映射中使用的是同一个
- [ ] 相机内参K在Ch2 EPnP、Ch3反投影中使用的是同一个
- [ ] CableMask在Ch3建图和Ch4前馈中来源相同（同一帧or时间对齐）
- [ ] 装配轴线方向v_asm/z_h在Ch3姿态相容性评价和Ch4误差分解中定义一致
- [ ] d_c线缆方向在Ch3 GRRT-Connect和Ch4 F_cable中消歧方式一致
